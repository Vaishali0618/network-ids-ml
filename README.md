# Network Intrusion Detection System

ML-based IDS trained on CICIDS 2017 dataset to detect DDoS attacks.

## Models Used
- Random Forest — 99.98%
- XGBoost — 100.00%
- SVM — 99.33%

## Tech Stack
Python, Scikit-learn, XGBoost, SHAP, Matplotlib, Streamlit

## Project Structure
- notebooks/ — training and analysis scripts
- reports/ — charts and SHAP plots
- models/ — saved trained models
- data/ — dataset (not pushed, too large)
